# Digital-Voltmeter-Using-Arduino
A digital voltmeter simulation built with an Arduino Uno (ATmega328P). It safely measures external DC voltages using a hardware voltage divider (90.9kΩ/10kΩ) to step down the input. The firmware leverages the internal 10-bit ADC to calculate the original source voltage, outputting real-time data to an I2C 16x2 LCD. Fully validated using Wokwi
